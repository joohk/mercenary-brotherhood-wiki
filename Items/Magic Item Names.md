How randomly generated magic items get their names: the item's rarity picks the naming pattern and its magic properties pick the theme words.

## Naming patterns

Each magic property belongs to a *family*, and every family maps to one of 22 naming themes. The item's rarity decides which pattern is used.

| Rarity | Pattern | Example |
|---|---|---|
| Uncommon | Theme adjective + item name | *Crackling Steel Sword* |
| Rare | Item name + theme suffix (two-theme suffixes for some theme pairs) | *Steel Sword of the Storm* |
| Epic | Compound name: theme prefix + theme suffix (special names for some theme pairs) | *Stormcaller* |
| Legendary | A unique name from a fixed list per item kind, picked by theme hints | *Widow's Wail* |
| Ascendant | A unique name from a separate list per item kind, picked by theme hints | *Echo of the First Flame* |

Example words are the first entries of the *Lightning* theme. When no theme fits, the generic words below are used; cursed items draw on their own adjective list.
