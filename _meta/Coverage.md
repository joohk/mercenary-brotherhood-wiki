| File | Status | Reason |
|---|---|---|
| `balance/progression_snapshots.json` | Excluded | Developer balance-test snapshots; not player-facing. |
| `balance/scenarios.json` | Excluded | Developer balance-test scenarios; not player-facing. |
| `encounters/encounter_config.json` | Config | Terrain to encounter-table mapping and multipliers; rendered with encounter tables. |
| `enemies/warband_config.json` | Config | Warband spawning tuning; rendered as a Mechanics page. |
| `items/item_icons.json` | Config | Item icon lookup; used to pick each item's icon. |
| `items/magic_names.json` | Config | Name fragments for random magic items; rendered as a Mechanics page. |
| `pois/tavern_rumors.json` | Config | Tavern rumor templates; rendered as a Mechanics page. |
| `presets/long_term.json` | Excluded | Developer test save preset; not player-facing. |
| `races/_racial_relations.json` | Config | Race-pair relation table; rendered as the Mechanics racial relations matrix and on race notes. |
| `settlements/market_specializations.json` | Config | Per-settlement market goods; folded into settlement notes. |
| `skills/_tutorial_skill_offers.json` | Config | Tutorial skill offers per archetype; folded into skill notes. |
| `vendetta/name_pools.json` | Config | Vendetta champion name pools; rendered on the vendetta page. |
| `vendetta/vendetta_speeches.json` | Config | Vendetta death speeches; rendered on the vendetta page. |
| `world/realm_name_pools.json` | Config | Recruit name pools by realm; folded into a Mechanics page. |
